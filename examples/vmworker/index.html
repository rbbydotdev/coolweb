VMWorker

A Worker whose script runs in its own Linux VM. The script reads messages on stdin and posts them on stdout. CPU and memory limits are set per VM.

const vm = new VMWorker("worker.sh", { cpus: 2, memory: "512MB", serialization: "json" });
vm.onmessage = (e) => console.log(e.data);
vm.postMessage({ id: 1, cmd: "uname -a" });

webWorker.postMessage({ vm: vm.connect() }, [port]); // a Web Worker talks to the VM directly
